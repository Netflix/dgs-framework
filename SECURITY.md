# Security Policy

## Supported Versions

The following major versions are actively maintained and will receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 12.x (Spring Boot 4)  | :white_check_mark: |
| 10.x (Spring Boot 3)  | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities through Gibhub private security reporting.
